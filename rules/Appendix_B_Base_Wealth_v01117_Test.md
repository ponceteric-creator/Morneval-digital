# Appendix B Amendment — Family Base Wealth v0.11.17 Test

Status: **active balance-test hypothesis; not yet locked as the final tabletop value.**

Each Family has a permanent **base Wealth capacity of 2** each Generation instead of 1.

This changes only the Family baseline. All other Wealth sources remain additive and unchanged.

Current demand rewards remain:

| Demand served | Prestige to Stake owner | Wealth capacity generated |
|---|---:|---:|
| Population | +1 | 0 |
| Imperial | 0 | 0 |
| External Market | +1 | +1 |

Consequences intended for testing:

- a Family can support up to two 1-Wealth Agents from its base economy before earning any additional Wealth;
- External Market service remains valuable because it expands capacity beyond that baseline;
- Population demand does not generate Wealth;
- Imperial demand does not generate direct Family Wealth or Prestige.

The 12 structural Renown endgame trigger is unchanged for this test so the effect of the Wealth baseline can be measured directly.
